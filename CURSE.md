# Peggle Forever

**PopCap's Peggle is back in World of Warcraft.** The original 2009 Peggle addon, updated to run on WoW Forever.

In 2009 PopCap released a full version of Peggle that ran inside the WoW client: aim, fire, clear the orange pegs, and hope for Fever. It stopped working long ago as the game's interface changed. Peggle Forever brings it back: the same game, levels, art and sounds, with a compatibility layer that fills in everything the modern client removed.

## Features

- **The full game.** 12 levels themed on WoW's cities and landmarks, from Ironforge and Orgrimmar to Dalaran and Icecrown Citadel, with Peggle's physics, free-ball bucket, style shots and Fever.
- **Talents.** Spend points on passive talents that affect all your characters, on a talent tree in the style of WoW's own.
- **Duel Mode.** Challenge another player to a 1-on-1, ten-ball game on the level of your choice. Your last ten opponents are kept in a drop-down for quick rematches, and the summary screen breaks down how you both scored.
- **Battle Mode.** Set up a contest for your friends and guildmates. Pick the level, the number of shots each person gets and how long the battle runs, then send the invites and watch the leaderboard.
- **Peggle Loot.** Settle loot disputes the Peggle way. The Master Looter types `/peggleloot`, and everyone in the group with the addon gets one shot on a random level to win the item. Talents are turned off and everyone plays as Splork, so it's fair.
- **Brag.** Post your results to guild, party, raid or a custom channel.
- **Plays nicely with the rest of the game.** Have it open itself when you take a flight, die, log in or get a duel invite, and close itself when you land, a ready check starts or you enter combat.

## Options

Open the game and go to its options screen.

- **Sounds:** Normal, Quiet or Off.
- **Mouse-on / Mouse-off Transparency:** fade the window when your mouse isn't over it.
- **Lock Window**
- **Show Mini-map Icon**
- **New Game on Flight Start**
- **Color Blind Mode**
- **Hide Outdated Chat Notifications:** stop the warnings about players on very old versions of Peggle.
- **Auto-Open:** On Flight Start, On Death, On Log-in, Duel Invite.
- **Auto-Close:** On Flight End, On Ready Check, On Enter Combat, Duel Complete, Peggle Loot Complete.
- **Duel/Battle Invites:** Chatbox Text Alert, Raid Warning Text Alert, Mini-map Icon Alert, or Auto-decline Duels.

## Slash Commands

| Command | Action |
| --- | --- |
| `/peggle` or `/peg` | Show or hide the game |
| `/peggle resetwindow` | Move the window back to the centre of the screen at its default size |
| `/peggle achievement` | Replay the easter egg, once you've unlocked it |
| `/peggleloot [item]` | Start a Peggle Loot challenge (Master Looter only). Shift-click an item to link it |

## Notes

- Built for WoW Forever (Interface 16001).
- Duels, battles and Peggle Loot only work with other players running this version.
- If you install it by hand, the folder in your AddOns directory must be called `PeggleForever`.
- This is a compatibility update, so some parts of a 2009 addon may still turn up an error on the modern client. If you hit one, please report it with the error text (BugSack is a big help).

Bug reports and suggestions are welcome in the comments or on the [GitHub issue tracker](https://github.com/sam-k-taylor/PeggleForever/issues).
